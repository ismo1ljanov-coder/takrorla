# Takrorla — Qur'on hifzi

Har kuni bitta sahifa yodlash va takrorlash uchun veb-ilova.

- Sahifa bo'yicha yodlash (Madina mushafi, 604 bet), 4 bosqichli usul
- Takrorlash jadvali: 1, 3, 7, 14, 30, 60, 120 kun
- 114 sura, 30 juz, sahifa bo'yicha o'qish
- Tarjima va izohlar: Shayx Muhammad Sodiq Muhammad Yusuf

## Ishga tushirish
Statik sayt: `index.html` + `data/`. Istalgan statik hostingda ishlaydi
(GitHub Pages, Render, Netlify). Mahalliy: `python3 -m http.server`.
